# Style Guide

1. Use inline comments to document the shape of tensors after any type of transformation/computation
2. Use recommended extensions for linting, formatting, and type checking
3. For Python code, use the [google style guide](https://google.github.io/styleguide/pyguide.html) as a baseline
4. You can ignore [rule 2.2](https://google.github.io/styleguide/pyguide.html) on imports
5. For [rule 3.2](https://google.github.io/styleguide/pyguide.html), we use a line length of 115
6. If a function returns multiple values, create a response object so the values are named and described
